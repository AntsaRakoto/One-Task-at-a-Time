# One-Task-at-a-Time
Application Android simple et intuitive de gestion de tâches, conçue pour aider l’utilisateur à se concentrer sur une tâche à la fois.

## Contexte du projet
Ce projet a été réalisé dans un cadre personnel et pédagogique.
En tant qu’étudiante en informatique, je souhaitais concevoir
une application Android complète, simple et bien structurée,
afin de renforcer mes compétences en développement mobile et bonnes pratiques Android.

## Fonctionnalités
- Ajouter un projet et le temps envisagé pour le terminer
- Ajouter des tâches avec une durée pour chaque dans le projet
- Réaliser une tâche avec un minuteur
- Afficher la météo
- Afficher la progression du projet
- Affichage clair et minimaliste
- Interface simple et intuitive

## Technologies utilisées
- Kotlin
- Android Studio
- Android SDK
- Base de données : RoomDatabase
- XML (UI)
- API : OpenWeather

## Installation et lancement
1. Cloner le projet :
   git clone https://github.com/AntsaRakoto/One-Task-at-a-Time.git
2. Ouvrir le projet avec Android Studio
3. Lancer l’application sur un émulateur ou un appareil Android
